# 新宿决战 0.4.2

0.4.2 扩充整张新宿地图的商业门面、店铺入口、步行空间、植被和广告系统。中心商业街与歌舞伎町一番街保留更高密度，支路、办公区和外围采用更疏的分布；新增餐饮、咖啡、便利店、药妆、书店、办公门厅、卷帘店和服务入口。广告牌增加大小层次、侧墙竖幅、成组灯箱和大型立面广告，亮度带有柔和通电灯箱感，色彩保持夜景氛围。街道补充人行道、斑马线、薄铺装、雨棚、橱窗和多种低饱和树木、灌木与盆栽。

战斗方面，合成茈爆炸半径调整为 12.8 m，伤害保持 140；茈与灶·开的爆炸表现统一为短时球形能量闪爆和扩张冲击波。灶·开使用更强的橙红热闪光；虚式·茈的视觉能量半径提高约 35%，伤害与物理范围保持不变，放射线改为弧形能量带。效果通过主客机共用入口同步，移动端保留核心球壳和冲击波并限制同屏数量。

技能语音采用原速裁剪，释放后直接进入人声，不对原始音频加速；人声和背景音乐可分别调节。联机结算显示胜负、双方角色、血量和再战意愿，Relay 离房会停止本地连接并清理异步房间状态。局域网等待房间持续显示本机 IPv4 与端口。

发布包包含 Windows ZIP、Android ARM64 APK 和 macOS Universal ZIP。Android 版本为 0.4.2（versionCode 30），联机协议为 `shinjuku-lan-042-v1`，双方必须使用相同版本。Android 与 macOS 已完成构建和静态包检查，不代表实体设备游玩验证。Relay 验证为同一台电脑上的双进程测试，不等同于两台实体电脑异地实测。
