《新宿决战》0.4.3 免费更新，提供 Windows、macOS、Android 和网页版。

- **Windows x64**：下载 `ShinjukuDuel-0.4.3-windows-x64.zip`，完整解压后运行 `ShinjukuDuel.exe`。
- **macOS Intel / Apple Silicon**：下载 `ShinjukuDuel-0.4.3-macos-universal.zip`，解压后打开 `.app`。未做 Apple 公证，首次打开说明见包内文档。
- **Android 8.0+ ARM64**：下载 `ShinjukuDuel-0.4.3-android-arm64.apk`，版本代码 32，可覆盖相同签名的旧版。
- **网页直接玩**：[itch.io 游戏页面](https://soranatsu.itch.io/shinjuku-duel)。手机和平板请横屏。

本版修复 Windows 关闭代理后仍无法建房或加入、客机自身攻击动作不可见、局域网地址和连接设置残留问题，并改进移动同步、手机和平板触控及地面和广告牌闪烁。

Windows / Android MatePad 局域网及无代理远程连接已获用户实测确认。Windows 通过 127 项回归检查和 51 项无代理持续联机检查。macOS 完成构建与 Universal 架构、文件及权限验包，尚无 Mac 实机运行结果。公网时延仍取决于双方网络。

双方请使用本次 0.4.3 更新。不同网络与网页版通过“在线房间”邀请码联机；原生局域网使用主机 IPv4 和 UDP 7777。Windows 首次局域网连接可运行包内的防火墙修复工具。

完整操作和验证范围见附件 `使用说明.txt`、`RELEASE-NOTES.txt`、`manifest-0.4.3.json`；校验值见 `SHA256SUMS.txt`。素材来源记录随各平台游戏包保留。
