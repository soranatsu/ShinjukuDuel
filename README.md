# 新宿决战 · Shinjuku Duel

基于 Unity 制作的第一人称单人人机对战游戏。选择五条悟或两面宿傩，在可破坏的城市街区中使用近战、术式、领域和防御技能进行战斗。

## 游戏内容

- 两名可选角色、三档 AI 难度，以及分步操作教学。
- 近战、格挡反击、黑闪、蓄力大招、领域对抗及 X 防御结界。
- 破坏建筑、踏墙移动、二段跳和短暂滞空。
- 主菜单与暂停设置：音量、键位、灵敏度、镜头动态和伤害飘字。
- 手机和平板触控操作，支持拖动并缩放按钮与摇杆。
