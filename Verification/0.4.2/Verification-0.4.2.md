本版使用最终候选 candidate9。Windows 受检程序集 SHA-256：
`643E69CA4AEDB90252C75789AF11AC9DCD543A5AC4B5445459C3A66C87700415`。

## Windows 运行与画面

- 核心验收 17 组、411 项通过：融合茈、位置校正、领域内投射物、动作衔接、空中移动、街景、建筑、近身 AI、御厨子实体、城市布局、语音、无量空处落脚、建筑同步、0.4.2 门面植被、爆炸及房间生命周期。
- 最终画面共 96 张，覆盖城市、领域、自由瞄准、肩膀、桌面/触控界面、音量设置、街景、联机胜负和爆炸。D3D11 与 D3D12 各检查 3 种爆炸、12 帧，均通过；图像检查确认非黑且对应实际效果存活时间。
- 教学离开后鼠标可见且未锁定。LAN 创建房间后保留本机地址和端口。联机结算显示胜负、双方角色、血量、再战与退出操作；胜负截图通过真实绘制界面并注入两种结算状态检查。
- 门面覆盖 185 栋建筑、369 个入口标记；植被 196 组、6 类，覆盖四个方向与外围。受检同层同向主招牌矩形重叠数为 0；植被未占用中心车道、入口通道和建筑占地。
- 合成茈伤害 140、爆炸半径 12.8 m、融合触发半径 2 m；普通茈 9.6 m、开 13.44 m。茈的视觉半径扩大 35% 不改变伤害判定。爆炸使用球形闪爆、冲击波和弧形能量带，无烟柱和蘑菇云，1.5 秒内清理且无新增物理组件。

证据目录：`Verification-Network/Experimental042-FinalCore-Candidate9` 与 `Verification-Network/Release042-Candidate9-*`。

## 联机

- Gojo 主机 Relay：165 + 59 项通过；客机人为延迟 1200 ms 就绪，确认主机等待后再推进战斗。
- Sukuna 主机 Relay：165 + 59 项通过。两组均完成领域、苍赫合成茈、茈/开特效与音频事件、结算及两次再战。
- Relay 换位：23 + 18 项通过，包含双方发起、接受、拒绝、重复确认、超时、角色及待确认状态一致。
- Relay 生命周期：10 项通过，包含创建时取消、离房后旧 epoch 清零、Relay 创建/退出/重建。LAN 生命周期在核心验收中另检查。
- 连续 Relay：51 项通过；模拟弱网 LAN：43 项通过。两组均为 35 秒连续交战，主机目标 30 FPS、客机 120 FPS。弱网代理为单向延迟 70 ± 20 ms、3% 随机丢包，并确认双向确有丢包。
- 连续 Relay 客机远程显示位置误差 p95 为 0.578 m，前序未加该预测的同类候选对照为 0.870 m；本轮最大快照年龄约 0.133 s。弱网 LAN p95 为 0.602 m，最大快照年龄约 0.150 s。预测位移上限 1 m，69/71 ms 边界连续性检查通过。

误差指标是本机受控场景的角色显示位置偏差，不是公网延迟或任意两台电脑的性能保证。Relay 使用真实云服务、同一台 Windows 电脑上的两个独立进程；尚无两台实体电脑异地、长时间或跨平台联机实测。

## 语音与启动

- 两段领域语音仅删除指定静音区间的 2/3；保留原速、人声起音与尾音。独立逐采样重建检查确认新 PCM 等于原运行 PCM 删除指定片段；其余技能 PCM 保持原 SHA-256。
- 四段实际运行 PCM 加既有播放增益后的计算响度为 -18.00、-17.95、-17.99、-18.00 LUFS，差 0.05 LU；原始音频未加速。领域语音长度与尾段信号验收通过。
- 菜单 BGM 与“雨爱”保留原文件，按同一音量计算输出的响度差约 0.002 LU。人声和音乐分开调节；新回合与离房会停止旧战斗音频，自动测试进程静音。
- 本轮三次启动至菜单首次截图为 2663.8 / 3178.7 / 2696.0 ms，平均 2846.2 ms。0.4.1 历史样本均值为 6327.8 ms，但缓存和系统负载并未严格配对，因此仅作记录，不将差值解释为稳定提速比例。

响度为数字音频测量与播放增益计算，不等同于扬声器声压实测。启动结果仅对应本机本轮环境。

## 安装包与保留版本

发布门禁将 Windows ZIP 内程序集与上述受检 SHA 绑定，校验包内 SHA 清单和 ZIP CRC；Android 检查 `com.shinjuku.fanduel`、0.4.2 / versionCode 30、签名与包完整性；macOS 检查版本、Intel/Apple Silicon 通用架构、包内 SHA 与 ZIP CRC。最终通过结果及三平台文件 SHA-256 记录在 `manifest-0.4.2.json`。

Android 与 macOS 的跨平台构建和验包不代表实体设备上的游玩、触控、发热或兼容性验证。Android 沿用项目既有测试签名，macOS 无 Developer ID 签名与公证。

0.3.7.5 与 0.4.1 历史包及 0.4.1 运行程序集通过发布门禁校验保留；本版不覆盖其历史证据。
